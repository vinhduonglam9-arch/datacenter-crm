# 全画布跨类型智能对齐与等距分布系统

针对画布中同时存在**干系人卡片、几何形状、作战便签、文本框、阵营分组框**等多类战术元素的高密度场景，构建一套支持**拖拽实时智能参考线磁吸（Smart Guides）**与**跨类型混合多选批量对齐/等距分布**的排版系统。

## 用户确认项与核心决策

> [!IMPORTANT]
> 以下关键交互方案已根据您的偏好确认，将在确认执行后直接落地：

- **确认决策 1 — 跨类型混合对齐范围**：支持将干系人卡片、几何形状、作战便签、文本框、阵营分组框纳入统一的包围盒坐标空间，支持不同类型元素混合框选后一键统一对齐与等距分布。
- **确认决策 2 — 拖拽智能参考线（Smart Guides）交互**：拖拽任意单个或多选元素时**默认开启实时对齐参考线与自动磁吸**（捕捉画布中其他元素的左/中/右/顶/中/底边缘及等间距），按住 `Alt` 键可临时抑制磁吸进行自由微调。
- **确认决策 3 — 批量对齐操作栏位置**：当框选或按住 `Shift` 多选**任意 2 个及以上画布元素**（无论同类型或跨类型混合）时，在画布**顶部浮动操作栏**自动呈现纯图标化的 6 向对齐（左、水平居中、右、顶、垂直居中、底）与 2 向等距分布（水平等距、垂直等距，3 个及以上元素可用）按钮组。

## 1. 功能概览与核心价值

- **核心能力**：
  1. **跨类型混合批量对齐（6 向对齐 + 2 向等距分布）**：打破原先仅限「2 张及以上人物卡片」才能对齐的限制。现在无论选中「人物卡 + 作战便签」、「多个几何形状 + 文本框」还是「分组框 + 人物卡」，只要选中的可移动画布元素总数 $\ge 2$，均可一键完成左对齐、水平居中、右对齐、顶对齐、垂直居中、底对齐；选中总数 $\ge 3$ 时可一键完成水平等距分布或垂直等距分布。
  2. **实时拖拽智能参考线与磁吸（Smart Alignment Guides）**：在拖拽画布元素（或拉伸几何形状/分组框尺寸）时，自动检测与周围可见元素的**左边缘、水平中心线、右边缘、上边缘、垂直中心线、下边缘**对齐关系。当距离小于阈值（如 `6px`）时自动精准吸附，并在画布叠加层绘制清晰的洋红/亮蓝智能对齐虚线与对齐锚点标记。
  3. **按住 `Alt` 键临时绕过磁吸**：拖拽过程中按住 `Alt` 键可即时关闭磁吸与参考线，松开 `Alt` 键恢复智能捕捉。
- **适用场景**：政企与算力中心复杂项目拓扑图的快速规整、多形状流程图对齐、便签批注与目标人物卡片的平行对齐。

## 2. 用户体验与视觉设计

- **核心交互流程**：
  1. **单元素/组合拖拽实时对齐**：用户按住画布中的人物卡、几何形状、便签或文本进行拖动 $\rightarrow$ 靠近其他元素的中心线或边缘（$\le 6\text{px}$）时自动微吸附 $\rightarrow$ 画布浮现 `1px` 高对比度智能参考线及距离标注 $\rightarrow$ 松手完成精准落位。
  2. **混合框选批量对齐**：用户使用选择工具框选或 `Shift+点击` 选中多个不同类型元素 $\rightarrow$ 顶部居中浮动栏即时展开纯图标对齐组 $\rightarrow$ 点击对应对齐或等距分布图标 $\rightarrow$ 所有选中元素按联合包围盒基准一次性精准对齐并记录撤销历史（支持 `Ctrl+Z` 一键回退）。
- **视觉规范与图标化设计**：
  - **智能参考线视觉**：采用 `#F43F5E`（玫瑰红/洋红）与 `#2563EB`（科技蓝）高辨识度 `1.5px` 虚线（随画布缩放保持恒定屏幕线宽），在线段两端对齐特征点处渲染 `3px` 十字/菱形捕捉标记。
  - **顶部多选浮动操作栏**：延续全图标化设计语言，不含冗余文字，每个对齐图标配备清晰的悬停提示（Tooltip），并使用 `tabular-nums` 等宽数字展示当前已选元素总数。

## 3. 关键技术决策与权衡

- **决策 1：统一包围盒抽象模型（Unified Bounding Box Abstraction）**
  - *方案*：将画布上的 `Person`（固定宽高 `248×142`）、`GroupFrame`（动态 `width × height`）以及 `CanvasAnnotation`（含几何形状、作战便签、文本框、手绘笔迹，动态 `width × height`）统一映射为标准的 `{ kind, id, x, y, width, height, locked }` 矩形包围盒参与空间计算。
  - *原因*：保证不同尺寸的元素在居中对齐、右对齐、底对齐以及等距分布时，严格按照各自真实几何尺寸计算间隔与中心，避免因尺寸差异产生错位。
- **决策 2：视图范围内的轻量级空间捕捉计算**
  - *方案*：拖拽时仅遍历当前画布可见且未处于被拖拽集合内的元素，分别在 X 轴（左、中、右）与 Y 轴（顶、中、底）查找最小偏差且小于 `6 / zoom` 的最佳对齐线。
  - *原因*：计算复杂度为 $O(N)$，在百级节点下依然保持 $60\text{fps}$ 零延迟丝滑拖拽体验。

## 4. 技术架构与数据流

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        统一画布空间几何对齐引擎                         │
│  Unified Element Box: { kind: 'person'|'frame'|'annotation', x,y,w,h }  │
└───────────────────┬─────────────────────────────────┬───────────────────┘
                    │                                 │
       ┌────────────▼────────────┐       ┌────────────▼────────────┐
       │  拖拽智能参考线捕捉器   │       │  跨类型批量对齐/分布器  │
       │  (Smart Guide Snapper)  │       │ (Batch Align/Distribute)│
       └────────────┬────────────┘       └────────────┬────────────┘
                    │                                 │
  • 对比静态元素 X(左/中/右)        • 计算选中集联合边界 (Min/Max/Center)
    与 Y(顶/中/底) 特征线           • 6 向边缘/中心对齐坐标重算
  • 距离 ≤ 6px 自动吸附 (Alt 禁用)  • 水平/垂直真实宽高净间距等距分布
  • 输出激活的垂直/水平参考线段     • 一次性提交历史记录 (Undo/Redo)
                    │                                 │
       ┌────────────▼────────────┐       ┌────────────▼────────────┐
       │  SVG 顶层参考线渲染层   │       │  顶部浮动多选图标操作栏 │
       │  (Active Snap Guides)   │       │ (2+ 元素对齐/3+ 等距)   │
       └─────────────────────────┘       └─────────────────────────┘
```

- **状态与交互映射**：
  - **拖拽状态 (`activeSnapGuides`)**：存储当前触发的垂直参考线（`x, y1, y2`）与水平参考线（`y, x1, x2`），在鼠标松开（`mouseup`）或按下 `Alt` 键时自动清空。
  - **跨类型批量对齐处理器 (`handleBatchAlignElements`)**：接收当前选中的 `personIds`、`frameIds`、`annotationIds` 与对齐指令（`left | center-h | right | top | center-v | bottom | distribute-h | distribute-v`），自动过滤已锁定（`locked`）元素，同步更新三类实体的状态并写入撤销栈。
